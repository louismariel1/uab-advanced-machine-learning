## Section A — Understanding Prototypical Networks

### Question 1. What is a Prototypical Network (ProtoNet)?

A. A supervised learning algorithm that uses a fixed classification head for all classes.

B. A few-shot learning model that classifies examples by comparing their embeddings with class prototypes.

C. An unsupervised learning algorithm that groups images without labels.

D. A gradient-based meta-learning algorithm that updates its initial parameters towards task-adapted parameters.

Correct answer: BExplanation:

ProtoNet is a few-shot learning method that uses an embedding space and class prototypes.

It calculates a prototype for each class by averaging the embeddings of its labelled support examples.

Query examples are then classified according to their distances from these prototypes.

Unlike a conventional classifier, ProtoNet does not need a fixed learned classification head for all possible classes.

### Question 2. What is the main purpose of a class prototype?

A. To represent the average embedding of the support examples belonging to a class.

B. To store the original image pixels.

C. To represent the query-set accuracy.

D. To replace the convolutional backbone.

Correct answer: AExplanation:

A prototype is the mean embedding of all support examples belonging to a particular class.

Mathematically:

$$
c_k=\frac{1}{|S_k|}
\sum_{(x_i,y_i)\in S_k}f_\theta(x_i)
$$

Where:

- $c_k$: Prototype of class $k$.
- $S_k$: Support examples belonging to class $k$.
- $f_\theta(x_i)$: Embedding generated by the backbone.

The prototype acts as a representative feature vector for its class.

### Question 3. Why does ProtoNet not need a conventional learned classification head?

A. Because it does not use class labels.

B. Because it uses class prototypes calculated from the support set to classify query examples.

C. Because it does not use a backbone.

D. Because it always predicts the first class.

Correct answer: BExplanation:

A conventional classifier usually has a fixed output neuron for each training class.

ProtoNet instead calculates new prototypes for the classes present in each task.

This allows it to classify previously unseen categories without requiring a permanently learned output neuron for every new class.

### Question 4. What is the role of the backbone in ProtoNet?

A. It calculates the cross-entropy loss directly.

B. It converts input images into feature embeddings.

C. It assigns the final class labels without comparing distances.

D. It stores the support-set labels.

Correct answer: BExplanation:

The backbone extracts useful visual features from images and converts them into numerical embeddings.

The same backbone processes both support images and query images.

ProtoNet then uses these embeddings to construct prototypes and calculate query-to-prototype distances.

## Section B — Understanding Embeddings and Prototypes

### Question 5. What is an embedding in ProtoNet?

A. A numerical representation of an input image in a learned feature space.

B. A classification accuracy value.

C. A collection of query labels.

D. A learning-rate parameter.

Correct answer: AExplanation:

An embedding is the feature vector generated by the backbone:

$$
z=f_\theta(x)
$$

Ideally, images belonging to the same class have similar embeddings, while images from different classes have more distinguishable embeddings.

The quality of this embedding space is crucial to ProtoNet's performance.

### Question 6. Suppose three support images from the same class produce these embeddings:

$$
z_1=(1,2),\quad
z_2=(2,3),\quad
z_3=(3,1)
$$

What is their class prototype?

A. $(1,2)$

B. $(2,2)$

C. $(3,3)$

D. $(6,6)$

Correct answer: BExplanation:

The prototype is the mean of the embeddings:

$$
c=\frac{z_1+z_2+z_3}{3}
$$

Calculate each dimension separately:

$$
c_1=\frac{1+2+3}{3}=2
$$

$$
c_2=\frac{2+3+1}{3}=2
$$

Therefore:

$$
\boxed{c=(2,2)}
$$

### Question 7. Why does ProtoNet calculate the mean embedding for each class?

A. To increase the number of support images.

B. To create a representative feature vector for each class.

C. To remove the backbone from the model.

D. To calculate the query labels automatically.

Correct answer: BExplanation:

The mean embedding summarises the feature representations of the support examples belonging to a class.

Rather than comparing each query image against every support image individually, ProtoNet compares it against one representative prototype per class.

This makes classification simple and computationally efficient.

## Section D — Euclidean Distance and Query Classification

### Question 15. What distance metric does the practical use to compare query embeddings with class prototypes?

A. Manhattan distance.

B. Cosine similarity.

C. Euclidean distance.

D. Hamming distance.

Correct answer: CExplanation:

The practical uses Euclidean distance:

$$
d(z,c_k)=
\sqrt{\sum_j(z_j-c_{k,j})^2}
$$

It measures the straight-line distance between a query embedding and a class prototype in the embedding space.

A smaller distance indicates a closer match.

### Question 16. What does `torch.cdist()` do in ProtoNet?

A. Calculates the distance between query embeddings and all class prototypes.

B. Calculates cross-entropy loss.

C. Creates class labels.

D. Updates the model parameters.

Correct answer: AExplanation:

`torch.cdist()` efficiently calculates pairwise distances between two sets of vectors.

For example:

python

```python
distances = torch.cdist(
    query_embeddings,
    prototypes,
    p=2
)
```

The argument `p=2` specifies Euclidean distance.

If there are 75 query embeddings and five prototypes, the resulting distance matrix has shape:

python

```python
(75, 5)
```

### Question 18. Why does ProtoNet use negative distances as classification logits?

A. Because larger distances should receive higher probabilities.

B. Because smaller distances should correspond to larger logits.

C. Because cross-entropy only accepts positive values.

D. Because negative distances eliminate the need for labels.

Correct answer: BExplanation:

Conventional classification logits work such that larger values indicate stronger support for a class.

Distances have the opposite interpretation: smaller values indicate a better match.

Therefore, ProtoNet negates the distances:

$$
\boxed{z_k=-d(z,c_k)}
$$

This ensures that the closest prototype receives the largest logit.

### Question 19. If the distances are:

Correct answer: BExplanation:

Simply multiply every distance by negative one:

$$
z=-d
$$

Therefore:

$$
\boxed{z=[-1,-3,-2]}
$$

The largest logit is -1, corresponding to the nearest prototype.

## Section E — Understanding Temperature

### Question 20. What is the purpose of temperature in ProtoNet?

A. To control the number of support examples.

B. To control the scale of the classification logits and the sharpness of the resulting probability distribution.

C. To change the number of classes.

D. To determine the embedding dimension.

Correct answer: BExplanation:

ProtoNet uses temperature $T$ to scale the negative distances:

$$
\boxed{z_k=-\frac{d(z,c_k)}{T}}
$$

Temperature influences how strongly the softmax probabilities distinguish between classes.

It does not change the ordering of distances when $T$ is positive.

### Question 21. What happens when the temperature is greater than 1?

A. The logits become less extreme, generally producing softer probability distributions.

B. The model changes the number of prototypes.

C. The nearest prototype becomes the farthest prototype.

D. The backbone stops producing embeddings.

Correct answer: AExplanation:

When $T>1$, dividing negative distances by a larger number reduces their magnitude.

This generally produces a softer probability distribution.

The closest prototype remains the predicted class because positive temperature does not change the ordering of logits.

### Question 22. What happens when the temperature is very small and positive?

A. The logits become less extreme.

B. The logits become more extreme, generally making the probability distribution sharper.

C. All class prototypes become identical.

D. The distances become zero.

Correct answer: BExplanation:

When temperature is very small and positive:

$$
z_k=-\frac{d_k}{T}
$$

The differences between logits become more pronounced.

Consequently, the softmax distribution generally concentrates more strongly on the nearest prototype.

### Question 23. Why must temperature be positive?

A. To ensure the distance ordering is preserved when converting distances into logits.

B. To guarantee that all embeddings are positive.

C. To eliminate the need for cross-entropy loss.

D. To ensure that every class has the same prototype.

Correct answer: AExplanation:

The implementation checks:

python

```python
if temperature <= 0:
    raise ValueError("temperature must be positive")
```

A positive temperature preserves the intended relationship: smaller distances produce larger logits.

A negative temperature would reverse that relationship, while zero would cause division by zero.

### Question 25. Which statement best describes the complete ProtoNet classification process?

A. Train a fixed classifier on all classes and reuse it without modification.

B. Extract support embeddings, calculate class prototypes, extract query embeddings, calculate negative distances and classify queries.

C. Fine-tune a new backbone separately for every query image.

D. Calculate query accuracy before constructing prototypes.

Correct answer: BExplanation:

The complete ProtoNet process is:

1. Support images pass through the shared backbone.
2. Support embeddings are averaged by class to create prototypes.
3. Query images pass through the same backbone.
4. Query-to-prototype Euclidean distances are calculated.
5. Negative distances are converted into logits.
6. Cross-entropy can then evaluate the predictions against the true query labels.

The backbone is shared between support and query examples, allowing the model to learn an embedding space suitable for few-shot classification.

## Key formulas to memorise

1. Prototype calculation

$$
\boxed{
c_k=\frac{1}{|S_k|}
\sum_{(x_i,y_i)\in S_k}f_\theta(x_i)
}
$$

2. Euclidean distance

$$
\boxed{
d(z,c_k)=\sqrt{\sum_j(z_j-c_{k,j})^2}
}
$$

3. Temperature-scaled classification logits

$$
\boxed{
z_k=-\frac{d(z,c_k)}{T}
}
$$

4. Query classification loss

$$
\boxed{
L_{\text{query}}=
\operatorname{CE}(z_{\text{query}},y_{\text{query}})
}
$$

The central idea to remember

ProtoNet learns an embedding space in which examples from the same class are close together. It averages labelled support embeddings into class prototypes and classifies query examples according to their distances from those prototypes.

Support set → Embeddings → Prototypes → Query embeddings → Negative distances → Classification logits.
